# TS Academy Module 01 - Python for Data Science

Exercises and Gradebook assignment.

## Exercises
- indoor - print text in lowercase
- tip - calculate tip from meal cost and percent
- bank - greeting-based bank payment
- coke - coke machine with coins 25, 10, 5
- fuel - fraction to fuel gauge with E/F
- lines - count lines of code, skip blank/comments
- scores - read scores.csv, mean/median/top/bottom

## Gradebook
Run: python gradebook/gradebook.py gradebook/students.csv
Reads CSV, skips bad scores, prints stats, writes report.txt sorted highest to lowest with letter grades.
